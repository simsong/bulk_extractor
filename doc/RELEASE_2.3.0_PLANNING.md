# bulk_extractor 2.3.0 planning

This document identifies the active work proposed for the 2.3.0 development
cycle. GitHub issues in the [BE2.3.0 milestone](https://github.com/simsong/bulk_extractor/milestone/7)
are authoritative for status, assignment, discussion, and completion. Do not
duplicate issue checklists here.

## Release goals

1. Strengthen input validation and regression coverage for supported scanners
   and carved formats.
2. Improve the quality and reproducibility of test data across supported
   platforms.
3. Address selected scanner, configuration, and build-maintenance issues.
4. Evaluate new codec and carving capabilities with test vectors before adding
   them to the supported product surface.

## Acceptance standard

Each 2.3.0 change should have a focused test or a documented reason one cannot
be added. New decoder or carving support requires reproducible test vectors.
The release continues to use `make check`, source-distribution validation, and
the applicable platform CI jobs as release gates.
